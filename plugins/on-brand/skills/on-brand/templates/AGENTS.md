# Design system for {{Brand}}

This folder is {{Brand}}'s design system. Before creating or changing anything visual (pages, graphics, slides, documents):

1. Read `DESIGN.md` (look: tokens, colors, type, layout, Do's and Don'ts).
2. Read `PRODUCT.md` (audience, reasoning, copy rules).
3. Read the matching file in `formats/` if one exists.

Use the CSS variables in `tokens.css`. Don't introduce colors or fonts that aren't defined there. If you need a new value, propose it to the person and add it to DESIGN.md and tokens.css together.
